# Venova Studio

A web app for learning the Yamaha Venova YVS-100 from zero in 30 days: lessons, an interactive fingering chart with sound, play-along songs, a microphone tuner and note trainer, and a daily plan with a practice log and player profiles.

Open it at **https://heskeecl.github.io/venova-studio/** and, on an iPhone, add it to the Home Screen (Share → Add to Home Screen) so it opens full-screen and works offline.

Built with plain HTML, CSS and JavaScript (no frameworks, no accounts). Progress is stored on the device per player; use Plan → Backup to move it between phones.
